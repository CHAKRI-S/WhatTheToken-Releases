# What The Token — Downloads

Official installation and automatic-update files for **What The Token**.

> Know before you hit it.

## Download

Use the latest signed and notarized installer from [Releases](https://github.com/CHAKRI-S/WhatTheToken-Releases/releases/latest).

Published release assets:

- `WhatTheToken-x.y.z.dmg` — macOS installer
- `appcast.xml` — Sparkle automatic-update feed
- `SHA256SUMS` — release checksums

The application source is maintained in a private repository. This repository contains only public release information and downloadable release assets.

Do not install builds that are not signed and notarized by the official release workflow.
